# 優化後的產品開發提示詞

你是一位熟悉台灣國中小自然科教學、班級經營、教育資料隱私、Google Workspace 與響應式前端的產品設計師兼工程師。請打造一套繁體中文、行動優先的「自然課堂中控站」，供自然科教師在實體或線上課堂中使用。

## 產品目標

讓教師在單一入口完成課前準備、課中管理、課後評量與資料備份，減少在點名表、成績試算表、獎勵 App、計時工具及雲端硬碟之間切換。

## 核心使用者與情境

- 主要使用者：台灣國小中高年級與國中自然科教師。
- 裝置：教師筆電、教室觸控螢幕、平板與手機。
- 一堂課的關鍵流程：選擇班級 → 點名 → 顯示今日任務 → 啟動計時／分組／隨機點名 → 快速記錄觀察與正向點數 → 輸入形成性評量 → 查看個人與班級趨勢 → 備份。

## 必要功能

1. 班級與學生：CSV 匯入、學生狀態、出缺席、標籤、個別備註與搜尋。
2. 互動教室配置：依教師提供的自然教室平面配置呈現 5 張六人實驗桌與 1–30 號座位；點擊座位可點名、記錄觀察、給予點數，並提供隱藏姓名的投影模式。
3. 課堂觀察：一鍵記錄參與、合作、探究、操作安全、作業完成與需要支持；每筆含時間、課次、教師與備註。
4. 正向獎勵：可自訂行為類別及分值、個人／小組加點、兌換獎勵、完整點數流水帳，不公開負向標籤或排行榜。
5. 成績系統：建立評量、設定滿分與權重、輸入分數、自動換算平均、顯示趨勢與待補交名單；獎勵點數不得直接當成學業成績。
6. 自然課工具：倒數計時、碼表、隨機點名、公平分組、擲骰子、音量提示、實驗安全檢核、QR／連結捷徑及 PhET 外部資源入口。
7. 教學資源：上傳、分類、搜尋、下載與刪除教材；離線版存 IndexedDB，雲端版可同步 Google Drive。
8. 分析報表：班級出席、點數類型、評量平均、學生學習趨勢與需關注名單；圖表需有文字摘要及可存取標籤。
9. Google 生態系：透過 Google Apps Script Web App 與 Sheets 同步資料、用 Docs 產生個別學習報告、把檔案存至 Drive，並可將部署後網址嵌入 Google Sites。
10. 備份與可攜性：完整 JSON 備份／還原、學生與成績 CSV 匯出、同步狀態與最後成功時間；不得把 API 金鑰寫入前端。

## 設計與資料原則

- 使用繁體中文與台灣學校常用詞彙，風格清爽、自然、專業，不幼稚化。
- 所有主要操作在三次點擊內完成；觸控目標至少 44px。
- 行為紀錄預設僅教師可見；公開投影模式隱藏個人分數與備註。
- 以正向支持取代羞辱式排行；負向事件使用中性「需要支持」並要求備註。
- 明確分開「學業成績」「出席」「課堂觀察」「獎勵點數」。
- 不收集非必要個資；提供資料刪除、備份與保留期限設定。
- 支援鍵盤操作、焦點樣式、高對比、減少動畫偏好與手機版。

## 技術交付

- 多頁式 HTML5、CSS3、原生 JavaScript ES Modules；共用導覽與資料層。
- localStorage 儲存結構化資料，IndexedDB 儲存上傳檔案。
- Google Apps Script 介接範本需含 doGet／doPost、試算表分頁初始化、批次同步、Drive 上傳與 Docs 報告產生。
- 提供示範資料、README、資料結構、研究摘要、部署／串接指南與測試報告。
- 不得宣稱未實際授權或未驗證的雲端串接已完成。

## 驗收條件

- 可新增／匯入學生、點名、加點、兌換、建立評量、輸入成績、查看報表。
- 重新整理後資料仍在；JSON 備份後可清空再還原。
- 計時器、隨機點名、分組與骰子可操作。
- 上傳的離線教材可列出並下載。
- 未設定 Google 端點時，介面清楚顯示「本機模式」；設定後可測試連線並手動同步。
- 320px 到桌面寬度皆可使用，無阻擋操作的水平捲動，主控台無未處理錯誤。
